# 外部服务与数据去向

管理员使用 `/doctor`（本地 CLI 为 `cli2im doctor`）查看检查结果和服务清单。清单按当前启用的机器人生成，不从代理例外名单猜测服务用途。

| 服务 | 用途 | 会收到什么 |
|---|---|---|
| 飞书 / Lark、Telegram | 收消息、发回复、收发文件 | 该平台上的机器人对话、附件、回复及会话标识 |
| Claude Code、Codex、AGY、Kimi 等 CLI 配置的模型服务 | 处理任务和生成回复 | 提示、必要的对话、附件及任务中读取的文件和工具结果 |
| DashScope 语音识别 | 语音转文字 | 完整语音文件 |
| DashScope 语音回复 | 文字转语音 | 需要朗读的回复文字 |

模型的实际供应商、地址和凭据由对应 CLI 配置决定。cli2im 不会因为某个域名出现在 `NO_PROXY` 中就调用它。DeepSeek、MiniMax、Moonshot 等名称如果只出现在旧代理例外里，不代表桥接程序正在把聊天发给这些服务；也不能据此排除 CLI 自己的供应商配置。

每个机器人可分别设置语音开关：

```yaml
bots:
  example:
    # 其他既有配置省略
    speech:
      stt: true   # 收到语音时，用 DashScope 转成文字
      tts: false  # 不将回复发送给 DashScope 合成语音
```

关闭识别后，语音不会送往识别服务；关闭回复后，文字不会送往合成服务。为兼容原有用法，未填写开关时保留语音功能。配置了密钥只代表可以尝试认证，不代表密钥有效、有余额或服务畅通。

`/doctor` 的“通过”只针对对应检查项：本地程序可启动不等于账号有效，连接流程启动不等于远端消息已验证，检测器加载不等于系统具有文件隔离或网络防漏能力。诊断不主动发送聊天消息或试用付费模型。

## 本地恢复记录

恢复目录保留每个获准会话最近一次任务结束时的回复文字，最多 1 MiB。**回复可能包含私人信息，甚至模型输出的凭据；缓存不是脱敏副本。** 它不额外复制机器人配置中的密钥或整个聊天记录。目录权限为 `700`，文件权限为 `600`，文件名由会话范围的哈希生成。长结果会标记截断。得到相同系统账户权限的程序仍可能读取缓存。

`/result` 由当前会话主动取回结果；重新启动不会自动重做任务，也不会自动补发无法确认是否已送达的消息。消息去重只保存哈希后的平台事件标识和时间，最多 10,000 条、24 小时。若程序在接收登记后、任务完成前退出，需要用户确认后重新提交；系统不会冒险重复执行。

长结果和诊断报告按页显示，例如 `/result 2`、`/doctor 2`；分页不会重新执行 AI 任务。
